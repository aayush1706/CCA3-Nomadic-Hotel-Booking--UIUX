# Nomadic — Hotel Booking UI/UX Redesign

## Project Overview
Nomadic is a hotel-booking website UI/UX redesign created as part of the CCA3 User Interface and User Experience Design assignment. The project focuses on improving the usability, navigation, and overall booking experience through a high-fidelity interactive prototype designed in Figma.

## Screens Designed
The Nomadic prototype includes the following five screens:
1. **Homepage** — Search interface for discovering hotels.
2. **Search Results** — Hotel listings for comparing available options.
3. **Hotel Details** — Information about a selected hotel and its facilities.
4. **Guest Details** — Form for entering guest and booking information.
5. **Payment** — Interface for proceeding with payment.

The screens are connected using Figma prototyping interactions to demonstrate the hotel-booking journey.

## Assignment Objectives
- Evaluate the usability of the original Booking.com website.
- Test the redesigned Nomadic prototype.
- Conduct think-aloud usability testing with five participants.
- Collect qualitative feedback and quantitative survey responses.
- Identify usability issues and opportunities for improvement.
- Compare the original interface with the redesigned prototype.

## Usability Testing Methodology
Participants are asked to complete the same hotel-booking task on both the original Booking.com website and the Nomadic prototype while expressing their thoughts aloud.

Testing involves:
- Observing navigation and task completion.
- Recording participant feedback with consent.
- Preparing transcripts of the recorded sessions.
- Collecting responses through the UX survey.
- Identifying recurring themes and usability issues.
